What’s supported — and what’s still a work in progress +

Images: PNG, JPEG, HEIC, TIFF, BMP, WebP, AVIF and SVG input routes. Select several files and convert them together to a common destination format. Availability depends on the destination codec. PNG → HEIC has been confirmed in the normal Mac app. WebP has a built-in lossless fallback; AVIF depends on an available codec.

PDF & text: merge, split, page organization, text/image extraction, text-to-PDF and some DOCX routes. No universal Office converter or OCR.

Media & subtitles: audio/video conversion and editing; SRT, VTT and text. Many routes need a separately installed FFmpeg. Codec support varies.

Limits: native image loading is limited to 100 MB and 40 megapixels. Archive conversion is disabled. Background framing does not remove backgrounds. Redaction and metadata tools are not certified anonymization tools. Not every route has been tested end to end.

No Terminal required for the download.

  1. Download & unzip

    Choose the ZIP for your Mac from the release. Double-click it in Downloads to extract Open Tangerine.

  2. Move it into Applications

    Drag Open Tangerine into Applications. Updating? Quit the running app first, then choose Replace when Finder asks. Back up your previous copy if you want a rollback.

  3. Open it & check the menu bar

    Open Tangerine lives in the menu bar. Drag a file and use Shift for conversion, Command for tools, or Control for actions.

Apple shows “Done” and “Move to Bin”? +

Click Done, then open System Settings → Privacy & Security. If the warning says Apple cannot check the app or the developer cannot be verified, review Apple’s opening guidance. Only if you trust the exact download, use the per-app Open Anyway option in System Settings → Privacy & Security, if available.

If macOS says the app is damaged or contains malware, stop and report the exact message. Do not disable Gatekeeper or strip quarantine flags. Building from source is another option for developers.

What is included?

Batch PNG, JPEG, WebP, TIFF and BMP output; image resize/rotation; image to PDF; PDF merge, split and text extraction; simple SRT/VTT conversion; SHA-256 checksums. Optional audio/video conversion uses your separately installed FFmpeg.

Platform differences: Windows includes the global Shift wheel, progress HUD, and background system tray; Linux uses the app window and progress panel. The physical Mac notch, HEIC/SVG routes and advanced Mac editors are not included. No Office converter or OCR. The motion demo above illustrates the Mac app.

Install the portable edition

Windows: extract the whole ZIP and run OpenTangerine.exe. Keep the _internal folder beside it. No administrator installation. This unsigned trial may trigger an unknown-publisher warning; do not disable system protection globally.

Linux: extract the tar.gz and run OpenTangerine. Requires an x64 desktop with glibc 2.39+ and X11/Wayland libraries. Ubuntu 24.04 is the CI baseline; other distributions and ARM are unverified.

Safety: originals are retained and existing outputs are never overwritten. Worker time/output limits are implemented, but this is not an OS security sandbox. Use trusted files and review results. Limits: 100 files, 100 MiB per input, 40 megapixels and 200 PDF pages.

A FEW GOOD QUESTIONS

Before you
take a bite.

Is it really free? +

Yes. Open Tangerine has no account, subscription or conversion quota. Its source is licensed under GPL-3.0-only. Optional third-party tools have their own licenses.

How do updates work? +

The app checks GitHub for a published release and opens this download page with your app version. This page tells you whether a newer version is available. Download it, quit the old app and replace it manually. It does not silently install anything.

Which platforms are supported? +

The native app targets macOS 26+ on Apple silicon. A separate early desktop edition targets Windows 10/11 x64 and Linux x64 (Ubuntu 24.04 baseline). Features differ: the physical notch remains Mac-only, while Windows supports the global Shift wheel. Intel Macs, Windows ARM and Linux ARM are unverified. Some operations require FFmpeg.

Is this made by Tangerine? +

No. Open Tangerine is an independent project by Sintax Error Private Limited, with its own artwork. It builds on Satsuma with the original MIT attribution preserved.

Can I help build it? +

Please do. Report a reproducible issue or propose a focused improvement on GitHub. Avoid uploading private files to public issues.
