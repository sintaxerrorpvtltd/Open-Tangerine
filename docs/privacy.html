OPEN TANGERINE / Privacy policy

Privacy policy

Last updated: 26 October 2026

This policy describes the current Open Tangerine desktop app and this download website, published by Sintax Error Private Limited.

Your files stay on your computer

The native Mac app processes selected files locally using macOS frameworks. The Windows/Linux desktop edition uses local Pillow and pypdf libraries. Some media operations use a separately installed FFmpeg executable that you select. We do not operate a file-upload or cloud-conversion service. Outputs are saved to your chosen destination. Temporary files may be created during processing. You control the originals and outputs.

No app account or analytics

The current app has no account system, advertising SDK, analytics or automatic crash-report upload. Diagnostic logging is off by default. If enabled, local logs can include filenames, paths, operation details and errors. Review and redact them before sharing.

Update checks and website visits

The native Mac app contacts GitHub to check published releases. The Windows/Linux edition opens the download website only when you click Downloads / updates; it does not perform background update requests. Manual checks run when requested; successful automatic checks are limited to once per day. Requests do not include your files or filenames. Opening the download page from the app includes only its version in the page URL so the page can compare versions.

GitHub hosts the website, repository and releases. GitHub receives ordinary request data such as IP address, browser or user-agent information, requested URLs and request times. Its own logging, retention and privacy practices apply. See GitHub’s privacy statement. The website also requests GitHub’s latest-release information to display the download.

The homepage loads a listing badge image from TryMacApps. Loading it sends ordinary request data, such as your IP address and browser information, to trymacapps.com, independently of your analytics preference.

Optional website analytics

Only if you choose “Allow analytics”, this website sends page views, GitHub-link clicks and download-button clicks to our own GoatCounter instance, hosted in a separate Open Tangerine Analytics project on Railway. It does not use PostHog or share the Some1.help analytics project. We send the page path, referring website domain or a simple utm_source campaign label, event type and release version for download clicks. Full query strings, referrer paths, files, filenames, form text and screen recordings are not sent.

GoatCounter receives your IP address and browser information with the request to estimate visits and approximate country. It does not store raw IP addresses in its analytics database, but our hosting provider may retain request logs under its own policies. Visit counts are estimates, not identified people. See GoatCounter’s privacy documentation and Railway’s privacy policy.

Download clicks do not prove a completed download or installation. GitHub separately provides aggregate release-asset download counts and repository traffic. These measurements can include repeat requests and our own tests.

Your choice and browser storage

Analytics are off until you allow them. “No thanks” keeps them off. We respect Do Not Track and Global Privacy Control. Use “Analytics preferences” in the footer to withdraw permission and stop future events. Only your choice and its expiry are stored locally for up to 180 days; no visitor or session identifier is saved by our integration, and no analytics cookies are set. Older integration identifiers are removed when this version loads. If browser storage is unavailable, your choice lasts only for this page. Withdrawing does not erase previously collected events; contact us about deletion requests.

All desktop editions remain free of analytics. The Windows/Linux edition stores your selected FFmpeg executable path in local application settings. Windows also saves whether its optional Shift wheel is enabled and the progress island style. When enabled, it polls modifier/mouse state and reads selected Explorer/Desktop file paths locally through Windows PowerShell; it does not record typed text or send selections to a server. It saves settings and the last successful update-check time locally. Host or external-site practices are governed by their own policies. Links to Instagram and other sites take you to services we do not control.

What you choose to share

GitHub issues, pull requests and discussions can be public. Do not post private files, passwords, identifying documents or unredacted logs. If you contact us, we use the information you provide to respond and maintain the project. We do not sell information submitted to us.

Control and questions

You can remove the app and its locally stored settings, delete local logs and outputs, or stop visiting this website. For privacy questions, contact sintaxerror.pvt.ltd@gmail.com. Requests concerning GitHub-hosted account or hosting records should also be directed to GitHub. We will update this page if the product’s data practices change.
